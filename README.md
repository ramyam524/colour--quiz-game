# Colour Quiz Game 🎨

A web-based Colour Quiz Game developed using Python Flask, HTML, CSS and SQLite.

## 📌 Project Overview

Colour Quiz Game is a simple web application where users can register, log in and participate in a colour-based quiz. The application checks the answers, calculates the score and stores the quiz results for viewing later.

## 🚀 Features

- User Registration
- User Login and Logout
- Colour Quiz
- Multiple-choice questions
- Automatic score calculation
- Percentage calculation
- Quiz result display
- Quiz history
- Result details
- SQLite database for storing data
- Responsive and simple user interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- Visual Studio Code
